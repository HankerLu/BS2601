## 基本格律

### 五言绝句
- 格式：每句5字，共4句，20字
- 押韵：第二、四句押韵，首句可押可不押
- 平仄：符合平仄交替规律

示例格式：
```
仄仄平平仄（起）
平平仄仄平（承）
平平平仄仄（转）
仄仄仄平平（合）
```

### 七言绝句
- 格式：每句7字，共4句，28字
- 押韵：第二、四句押韵，首句可押可不押
- 平仄：符合平仄交替规律

示例格式：
```
平平仄仄平平仄（起）
仄仄平平仄仄平（承）
仄仄平平平仄仄（转）
平平仄仄仄平平（合）
```

## 题目创作

### 题目格式要求
- **字数**：2-4字
- **风格**：文雅、含蓄、有诗意
- **避免**：通俗、直白、口语化

### 文雅词汇示例
**地点词汇**：
- 江畔、溪边、湖心、渡口、亭中、楼头、庭前、阶下
- 山巅、岭上、林中、竹里、松间、石上、舟中、马上

**时间词汇**：
- 春晓、夏夜、秋夕、冬晨
- 朝霞、暮云、斜阳、残月
- 风雨、雪夜、晴日、阴天

**动作词汇**：
- 独步、望远、听雨、观星、赏月、吟诗、倚楼、抚琴
- 夜泊、晚归、早行、久立、凝望、沉吟、忆旧、思乡

**意象词汇**：
- 孤舟、寒梅、幽篁、残荷、霜叶、寒江、空山、明月
- 清风、流云、落花、归雁、鸣蝉、萤火、疏影、暗香

### 题目模板

**模板1：[地点][动作]**
- 江畔独步、溪边听雨、亭中望远、楼头望月
- 庭前赏花、阶下观苔、林中漫步、竹里独坐
- 舟中望月、马上听风、松间问道、石上观云

**模板2：[时间][场景]**
- 春夜听雨、夏夜观星、秋夕望月、冬晨踏雪
- 朝霞映水、暮云遮山、斜阳归棹、残月照人
- 风雨夜归、雪夜寻梅、晴日游山、阴天听雨

**模板3：[意象][动作]**
- 孤舟夜泊、寒梅独开、幽篁独坐、残荷听雨
- 明月松间、清风竹里、流云山际、落花水面
- 归雁天边、鸣蝉树梢、萤火草间、疏影水中

**模板4：[情感][场景]**
- 独坐思乡、凝望忆旧、倚楼望远、抚琴寄怀
- 醉卧松间、闲游湖上、静听风声、细观花色

### 题目对比示例

| 文雅题目（✅） | 打油诗风格（❌） |
|---------------|----------------|
| 江畔独步 | 江边走走 |
| 月夜泊舟 | 晚上停船 |
| 春晓听莺 | 春天听鸟 |
| 独坐幽篁 | 自己坐竹林 |
| 亭中望远 | 亭里看山 |
| 庭前听雨 | 院里听雨 |
| 孤舟夜泊 | 船晚上停着 |
| 寒梅独开 | 梅花自己开 |

### 题目创作要点
1. **用词典雅**：避免"走、看、听、停、开"等通俗动词，使用"步、望、听、泊、开"等文雅动词
2. **画面感强**：题目应能唤起画面，如"江畔独步"能让人想到江边独行的场景
3. **意境含蓄**：不直接说出情感，通过场景暗示，如"独坐幽篁"暗示孤独
4. **字数适中**：2-4字最佳，过短信息不足，过长缺乏韵味

## 意象库

### 山水意象
- 山：孤山、远山、青山、云山、寒山
- 水：流水、江水、碧水、春水、寒水
- 天：明月、白云、清空、暮云、朝霞
- 地：荒原、芳草、古道、长亭、断桥

### 花鸟意象
- 花：桃花、梅花、杏花、菊花、莲花、落花
- 鸟：黄鹂、白鹭、孤鸿、燕雀、归雁
- 虫：蝉鸣、萤火、蜻蜓、蝴蝶

### 时令意象
- 春：春风、春雨、春草、春花、绿柳
- 夏：荷塘、蝉鸣、雷雨、绿荫、晚风
- 秋：秋风、落叶、明月、霜雪、菊花
- 冬：雪梅、寒江、冰凌、冬雪、枯木

### 情感意象
- 孤寂：孤舟、独酌、寒夜、残月、空山
- 欢愉：春游、欢歌、美酒、良辰、知己
- 思念：故乡、故人、远方、明月、书信
- 豪迈：壮志、长风、千山、万里、剑气

## 修辞手法

### 借景抒情
通过描写景物来表达情感，景为情用。
示例："月落乌啼霜满天，江枫渔火对愁眠"

### 对仗
词语、句式相对，形成工整美。
示例："两个黄鹂鸣翠柳，一行白鹭上青天"

### 托物言志
借具体事物表达志向或情感。
示例："千磨万击还坚劲，任尔东西南北风"（竹）

### 虚实结合
实写眼前之景，虚写心中之情。
示例："孤帆远影碧空尽，唯见长江天际流"

### 用典
引用历史典故或前人诗句。
示例："商女不知亡国恨，隔江犹唱后庭花"

## 常见体裁与模板

### 山水题材模板
**五言绝句**
```
第一句：写景起笔（山、水、天等）
第二句：承接扩展（景物细节）
第三句：转折抒情（表达心境）
第四句：收束总结（升华意境）
```

**七言绝句**
```
第一句：宏大景致开篇（全景）
第二句：近景细致描绘（特写）
第三句：情感转折（心境变化）
第四句：哲理或情感收尾
```

### 人物题材模板
**七言绝句**
```
第一句：人物活动或状态
第二句：所处环境描写
第三句：人物内心或情感
第四句：升华主题或感慨
```

### 时令题材模板
**五言绝句**
```
第一句：时令特点（季节、天气）
第二句：景物变化
第三句：时令情怀
第四句：人生感悟
```

## 创作要点

### 起句要抓人
第一句要能吸引读者，设置场景或意境
示例："君不见黄河之水天上来"

### 承句要铺陈
第二句承接第一句，展开描写或叙述
示例："奔流到海不复回"

### 转句要有力
第三句是全诗的转折点，要有新意
示例："人生得意须尽欢"

### 合句要有余韵
第四句收束全诗，留有余味
示例："莫使金樽空对月"

### 语言要求
- 词汇古雅，避免现代白话
- 用词精准，意境深远
- 节奏明快，朗朗上口
