## 基本格律

### 词牌简介
词牌是宋词的曲调名称，不同的词牌有不同的格律要求，包括：
- **字数**：每首词的总字数固定
- **句数**：词分上下片，每片的句数固定
- **字数分配**：每句的字数（形成长短句）
- **平仄**：每字的平仄要求
- **押韵**：押韵的位置和韵部

### 长短句特点
宋词的最大特点是长短句交错，形成独特的节奏美感：
- 短句：1-3字，营造急促、顿挫之感
- 中句：4-5字，平稳流畅
- 长句：7字以上，舒展奔放

### 押韵规则
- **平韵**：多用于表达欢快、豪放、开阔的情感
- **仄韵**：多用于表达悲凉、幽怨、沉郁的情感
- **换韵**：同一词中可换韵，但需符合词牌要求

## 题目创作

### 题目格式要求
- **字数**：2-4字
- **风格**：文雅、含蓄、有诗意
- **避免**：通俗、直白、口语化

### 文雅词汇示例
**地点词汇**：
- 楼头、庭院、深院、小楼、亭阁、轩窗、帘幕、画栏
- 溪桥、山居、湖畔、渡口、舟中、马上、林间、竹里

**时间词汇**：
- 春夜、夏夜、秋夕、冬晨
- 朝霞、暮云、斜阳、残月
- 风雨、雪夜、晴日、阴天

**动作词汇**：
- 倚楼、凭栏、听雨、观星、赏月、吟诗、抚琴、独坐
- 夜泊、晚归、早行、久立、凝望、沉吟、忆旧、思乡

**意象词汇**：
- 残荷、疏影、暗香、寒江、孤灯、残烛、空床、冷月
- 流云、落花、归雁、鸣蝉、萤火、霜叶、寒梅、幽篁

### 题目模板

**模板1：[地点][动作]**
- 倚楼望远、庭院独坐、小楼听雨、亭中赏月
- 深院观花、画栏观苔、溪桥听泉、山居观云
- 舟中望月、马上听风、林间问道、竹里独坐

**模板2：[时间][场景]**
- 春夜听雨、夏夜观星、秋夕望月、冬晨踏雪
- 朝霞映水、暮云遮山、斜阳归棹、残月照人
- 风雨夜归、雪夜寻梅、晴日游山、阴天听雨

**模板3：[意象][动作]**
- 残荷听雨、疏影横斜、暗香浮动、寒江独钓
- 流云山际、落花水面、归雁天边、鸣蝉树梢
- 萤火草间、霜叶山头、寒梅雪中、幽篁月下

**模板4：[情感][场景]**
- 独坐思乡、倚楼望远、凭栏忆旧、听雨寄怀
- 醉卧松间、闲游湖上、静听风声、细观花色

### 题目对比示例

| 文雅题目（✅） | 打油诗风格（❌） |
|---------------|----------------|
| 倚楼望远 | 楼里看远 |
| 庭院独坐 | 院里自己坐 |
| 小楼听雨 | 小楼听雨（相对文雅，但可优化） |
| 亭中赏月 | 亭里看月亮 |
| 深院观花 | 院里看花 |
| 画栏观苔 | 栏杆上看青苔 |
| 残荷听雨 | 枯荷花听雨 |
| 疏影横斜 | 影子斜着 |
| 暗香浮动 | 香味飘着 |
| 寒江独钓 | 冷江里钓鱼 |

### 题目创作要点
1. **用词典雅**：避免"看、听、坐、走"等通俗动词，使用"望、听、坐、步"等文雅动词
2. **画面感强**：题目应能唤起画面，如"倚楼望远"能让人想到倚在楼上眺望的场景
3. **意境含蓄**：不直接说出情感，通过场景暗示，如"庭院独坐"暗示孤独
4. **字数适中**：2-4字最佳，过短信息不足，过长缺乏韵味
5. **词牌契合**：题目可使用词牌名（如《蝶恋花》），或根据词牌意境创作

## 意象库

### 情感意象

#### 相思离别
- 楼阁：高楼、画楼、西楼、小楼
- 庭院：庭院、深院、小院、空庭
- 景物：栏杆、帘幕、窗纱、月光
- 动作：凭栏、倚楼、独倚、眺望

#### 豪放旷达
- 天地：天、地、日月、星辰、江河
- 动作：乘风、登高、望远、醉卧
- 意象：剑、酒、长风、云涛

#### 婉约哀怨
- 花草：落花、残花、败叶、枯荷
- 天气：风雨、霜雪、寒夜、黄昏
- 意象：孤灯、残烛、空床、冷月

#### 闲适恬淡
- 自然：云、水、山、林、鸟
- 活动：钓鱼、饮酒、赏花、听琴
- 意象：茅舍、溪桥、孤舟、渔火

#### 秋思
- 景物：秋风、落叶、明月、寒霜

#### 夏雨
- 景物：荷塘、蝉鸣、雷雨、绿荫

#### 冬雪
- 景物：雪梅、寒江、冰凌、冬雪

### 景物意象

#### 楼阁庭院
- 楼阁：高楼、画楼、西楼、小楼

- 门窗：窗纱、帘幕、朱户、画扇

#### 江河山峦

- 山：青山、远山、孤山、云山

## 创作要点

### 词牌选择与意境匹配
- **小令**：适合日常小景、闲适心情、细腻情感
  - 如梦令：轻灵婉约
  - 浣溪沙：典雅清丽

- **中调**：适合相思离别、闺怨愁绪、人生感悟
  - 蝶恋花：婉约细腻
  - 虞美人：悲凉沉郁

- **慢词**：适合豪放旷达、怀古咏史、宇宙情怀
  - 水调歌头：豪放旷达
  - 念奴娇：雄浑豪迈

### 长短句节奏感
- 短句（1-3字）：营造急促、顿挫、断续之感
- 中句（4-5字）：平稳流畅，承上启下
- 长句（7字以上）：舒展奔放，情感抒发

**示例节奏分析**：
```
常记溪亭日暮（平稳）
沉醉不知归路（流畅）
兴尽晚回舟（舒缓）
误入藕花深处（转折）
争渡（急促）
争渡（急促）
惊起一滩鸥鹭（奔放）
```

### 情感表达技巧
- **借景抒情**：通过景物描写暗示情感，如"明月不谙离恨苦"
- **托物言志**：借具体事物表达情感，如"落花人独立，微雨燕双飞"
- **虚实结合**：实景与虚景交织，如"梦里不知身是客"
- **对比手法**：今昔对比、物我对比，如"雕栏玉砌应犹在，只是朱颜改"

### 语言要求
- 词汇古雅典雅，避免白话
- 用词精准细腻，情感含蓄委婉
- 节奏明快，长短句协调
- 意象丰富，情景交融
