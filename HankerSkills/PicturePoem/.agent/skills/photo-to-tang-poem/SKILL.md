# 照片理解与古典诗词生成

## 任务目标
- 本 Skill 用于：根据用户提供的照片，理解其视觉内容并创作相应意境的唐诗或宋词，并可生成精美的图文卡片
- 能力包含：图像内容识别、意境情感提炼、唐诗风格创作、宋词风格创作、图文卡片合成
- 触发条件：用户上传照片并要求"写首唐诗"、"配诗"、"生成宋词"、"作首词"、"生成卡片"等

## 操作步骤

### 1. 图像理解
观察并分析照片，提取以下要素：
- **景物识别**：山水、花鸟、人物、建筑、天气、季节等
- **情感判断**：孤寂、欢愉、思念、豪迈、闲适等
- **意境把握**：整体氛围、时空背景、深层含义

### 2. 意境提炼
将视觉元素转化为诗意表达：
- 选择核心意象（如：明月、孤舟、落花、寒梅、高楼、庭院）
- 确定情感基调（如：惆怅、壮志、恬淡、相思、离别）
- 搭建场景框架（起承转合或上下片的结构设计）

### 3. 文学创作

根据用户需求选择唐诗或宋词创作：

#### 3.1 唐诗创作
基于提炼的意境，创作符合规范的唐诗：
- **选择体裁**：五言绝句（20字）或七言绝句（28字）
- **遵守格律**：平仄协调、押韵恰当
- **运用修辞**：对仗、借景抒情、托物言志等

参考 [references/tang-poetry-style.md](references/tang-poetry-style.md) 获取详细的创作规范和意象库。

#### 3.2 宋词创作
基于提炼的意境，创作符合规范的宋词：
- **选择词牌**：根据意境和情感选择合适的词牌（如：如梦令、浣溪沙、蝶恋花、水调歌头等）
- **遵守格律**：按词牌要求的字数、句式、平仄、押韵创作
- **运用长短句**：利用长短句的节奏变化，增强情感表达

参考 [references/ci-poetry-style.md](references/ci-poetry-style.md) 获取详细的词牌格律和创作规范。

#### 3.3 题目创作（重要）

为诗词创作文雅的题目，避免出现"打油诗"风格的通俗题目：

- **题目格式**：2-4字，简洁含蓄
- **用词要求**：
  - 使用古雅词汇（如：江畔、月夜、春晓、孤舟、幽篁）
  - 避免通俗词汇（如：吃饭、睡觉、江边、看山）
  - 避免直白描述（如：风景不错、心情很好）
  - 避免口语化表达

- **题目模板**：
  - **[地点][动作]**：江畔独步、亭中望远、庭前听雨、舟中望月
  - **[时间][场景]**：春夜听雨、秋山晚望、冬日踏雪、夏夜观星
  - **[意象][动作]**：孤舟夜泊、寒梅独开、明月松间、清风竹里

- **文雅题目示例**：
  - ✅ 江畔独步、月夜泊舟、春晓听莺、独坐幽篁（文雅）
  - ❌ 江边走走、晚上停船、春天听鸟、自己坐竹林（打油诗风格）

参考 [references/tang-poetry-style.md](references/tang-poetry-style.md) 获取详细的创作规范和题目示例。

### 4. 生成卡片（可选）

如果用户需要生成精美的图文卡片，调用 `scripts/generate_card.py` 合成卡片：

**调用方式**：
```bash
python scripts/generate_card.py \
  --image-path <照片路径> \
  --poem-text <诗歌文本> \
  --poem-title <诗词标题> \
  --poem-type <tang或ci> \
  --style <classical或modern> \
  --output-path <输出路径>
```

**参数说明**：
- `--image-path`：原始照片路径（必需）
- `--poem-text`：诗歌文本（必需）
- `--poem-title`：诗词标题（可选，默认"无题"）
- `--poem-type`：诗词类型（可选，"tang"或"ci"，默认"tang"）
- `--style`：卡片风格（可选，"minimal"或"instagram"，默认"minimal"）
  - `minimal`：极简杂志风（纯白背景、大量留白、超大标题、极简装饰）
  - `instagram`：清新ins风（淡蓝渐变背景、圆角照片、emoji装饰）
- `--output-path`：输出图片路径（可选，默认"card.png"）

**示例**：
```bash
# 生成极简杂志风唐诗卡片
python scripts/generate_card.py \
  --image-path ./photo.jpg \
  --poem-text "斜阳倒影入清流，一叶孤舟逐水流。" \
  --poem-title "江畔独步" \
  --poem-type tang \
  --style minimal \
  --output-path ./tang-card.png

# 生成清新ins风宋词卡片
python scripts/generate_card.py \
  --image-path ./photo.jpg \
  --poem-text "槛菊愁烟兰泣露，罗幕轻寒，燕子双飞去。" \
  --poem-title "蝶恋花" \
  --poem-type ci \
  --style instagram \
  --output-path ./ci-card.png
```

## 创作原则

### 题目创作原则（重要）
- **字数控制**：2-4字，简洁含蓄
- **文雅用词**：使用古雅词汇，避免通俗、直白、口语化表达
- **意境契合**：题目应与诗词意境相符，点明主题
- **含蓄优美**：避免直白描述，追求诗意和画面感
- **避免打油诗**：不使用"江边走走"、"晚上看山"等通俗表达

### 唐诗创作原则
- **意境优先**：诗歌应准确传达照片的情感和意境
- **格律规范**：确保符合唐诗的基本格律要求
- **语言典雅**：使用古雅词汇，避免白话表达
- **结构完整**：起承转合清晰，首尾呼应

### 宋词创作原则
- **词牌恰当**：根据意境和情感选择合适的词牌
- **长短协调**：充分利用长短句的节奏感，避免生硬
- **意境声律并重**：既要追求意境深远，又要符合声律要求
- **情感细腻**：宋词更适合表达细腻婉转的情感

### 卡片设计原则
- **风格统一**：卡片风格应与诗词意境相匹配（极简杂志风适合所有类型，清新ins风适合现代感强的内容）
- **图文协调**：照片与诗歌文字布局合理，层次分明
- **字体清晰**：确保中文字体显示正确，文字大小适中
- **大量留白**：极简杂志风强调留白，清新ins风强调柔和

## 使用示例

### 示例1：山水照片 - 唐诗 + 卡片
- 输入：一张傍晚江边孤舟的照片
- 输出1：七言绝句描述江边孤舟的孤寂意境
- 输出2：古典风格图文卡片（照片+诗歌）

### 示例2：花鸟照片 - 唐诗
- 输入：春天桃花盛开的照片
- 输出：五言绝句赞美春日桃花的美感

### 示例3：人物照片 - 宋词 + 卡片
- 输入：人物在庭院中思念远方的照片
- 输出1：《蝶恋花》风格宋词，表达细腻的相思之情
- 输出2：现代简约风格图文卡片（照片+宋词）

## 注意事项
- 充分利用智能体的图像理解和文本创作能力进行诗词创作
- 创作时可参考经典唐诗宋词的表达方式，但避免直接抄袭
- 根据照片内容和用户需求灵活选择唐诗或宋词
- 唐诗适合简洁凝练的表达，宋词适合细腻婉转的情感
- 确保诗词与照片意境高度契合，而非仅描写景物
- 生成卡片时，确保照片路径正确，脚本会自动处理图片大小和布局
- 卡片脚本使用Pillow库，需要系统支持中文字体（文泉驿、微软雅黑等）
