# 基于 Agent Skill 的新费曼学习法

## 核心主张

践行一种新的学习方式：把「做出一本好用的、贴合书中方法论的 Agent Skill」当作费曼学习法的输出环节。通过创作（做 Skill）把输入过程改造成输出过程，从而：
- 更深刻理解书籍内容
- 在后续生活与工作中更高效地运用这些方法论
- 促进知行合一：理论通过交互式助理落地为可执行的实践

## 做法简述

将各类实用书籍、方法论书、工具/理论书，转化为可交互的 Agent Skill（或自动化分析/咨询型 AI 助理），让「读懂—会做」在「做 Skill」的过程中完成。

## 可落地的书籍/方法论示例

- **方法论/实用书 → Agent Skill**：如《毛选》《高效能人士的七个习惯》《做对产品》《用户研究从入门到精通》《设计思维》《线性代数》等，均可做成对应方法论的 Agent Skill 或咨询助手。
- **传统先例**：21 世纪初任天堂将川岛博士的著作做成「脑锻炼」（Brain Training）游戏，即把书籍转化为实用交互工具的经典案例；本主张是在同一思路下，以 Agent Skill 为当代的产出形态。
