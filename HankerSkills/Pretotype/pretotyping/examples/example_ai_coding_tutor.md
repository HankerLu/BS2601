## 一、市场验证假设（XYZ公式）

### 核心假设

**至少 8% 的 想转行或提升技能的职场人士（25-40岁） 会 购买为期3个月的在线编程课程**

### 假设拆解

#### X - 预期转化率：8%

**选择依据**：
- 在线教育行业的平均付费转化率为5-10%
- 编程类课程由于门槛较高，转化率通常在中等水平
- 考虑到是新产品，采用相对保守的8%

**保守估计**：考虑到这是新产品且需要付费，我们采用行业中位数作为预期

#### Y - 目标用户：想转行或提升技能的职场人士（25-40岁）

**用户画像**：
- 年龄段：25-40岁
- 职业/身份：在职白领、传统行业从业者、想转行互联网的人
- 核心特征：
  - 有一定经济基础（月收入8k+）
  - 时间碎片化（工作日晚上+周末）
  - 学习动机强（转行/升职/副业）

**用户痛点**：
- 主要问题：工作忙没时间系统学习，传统课程进度固定跟不上
- 现有解决方案的不足：
  - 线下培训班：时间固定，需要请假
  - 录播课程：缺乏互动和个性化指导
  - 自学：没有规划，容易放弃

**市场规模估算**：
- 潜在用户数量级：中国一二线城市职场人士约5000万
- 有转行/提升意愿的：约10%（500万）
- 可触达用户：通过线上渠道可触达50-100万

#### Z - 目标行动：购买为期3个月的在线编程课程

**行动类型**：付费购买

**切身利益投入**：
- 投入类型：💰金钱 + ⏰时间
- 具体投入：
  - 金钱：¥1999（3个月课程）
  - 时间：填写详细需求问卷（10分钟）+ 预约试听（30分钟）
- 可信度评级：⭐⭐⭐⭐⭐ (金钱投入，最高可信度)

**可衡量性**：
- 追踪方式：支付成功订单数
- 数据来源：支付平台（微信支付/支付宝）+ 后台订单系统

### 验证标准

**最小样本量**：114 次曝光
- 计算依据：95%置信度，5%误差范围，8%预期转化率

**成功阈值**：至少 9 次转化
- 计算公式：114 × 8% ≈ 9

**推荐测试时长**：14 天（2周）
- 理由：给用户足够时间了解产品、考虑决策、完成支付

**置信度**：95%

### 关键风险假设

**最不确定的假设**：
1. 用户愿意为"AI个性化"功能支付溢价 - 风险等级：🔴高
2. 碎片化学习能达到系统学习的效果 - 风险等级：🟡中
3. 职场人士有足够的学习动力坚持3个月 - 风险等级：🟡中

**优先验证顺序**：
- 首先验证：用户是否愿意付费（最关键）
- 其次验证：AI功能是否是核心卖点

#### 📊 第4步：数据收集（预计 7-14 天）

**每日监控**：

**核心指标**：
- **曝光量**（Impressions）：多少人看到了你的内容/广告
- **点击量**（Clicks）：多少人点击进入落地页
- **页面浏览量**（Page Views）：落地页被浏览次数
- **点击购买次数**：点击"立即购买"按钮的次数
- **实际支付次数**：完成支付的订单数
- **转化率**：支付次数 / 页面浏览量

**辅助指标**：
- 流量来源分布（小红书 vs 知乎 vs 微信）
- 用户停留时间（平均多久）
- 跳出率（看一眼就走的比例）
- 设备类型（手机 vs 电脑）

**数据记录**：

**方式1：自动化**（推荐）
- 工具：Google Analytics 4
- 优势：实时、准确、可视化
- 查看方式：
  1. 登录GA4后台
  2. 查看"实时"报告
  3. 每天导出数据到表格

**方式2：手动记录**
- 工具：Google Sheets
- 模板：
  ```
  | 日期 | 曝光量 | 点击量 | PV | 点击购买 | 支付成功 | 转化率 | 备注 |
  |------|--------|--------|----|---------|---------|---------|----- |
  | 2/11 |        |        |    |         |         |         |      |
  ```
- 记录频率：每天晚上10点

**每日检查清单**：
- [ ] 查看GA4数据
- [ ] 记录到表格
- [ ] 分析流量来源（哪个渠道效果好）
- [ ] 查看用户反馈（评论、私信）
- [ ] 调整投放策略（如果某渠道效果差，减少投入）

**重要提醒**：
- ⚠️ 不要测试期间修改落地页（会影响数据对比）
- ⚠️ 记录所有异常情况（如某天流量突然暴涨）
- ⚠️ 保存用户的问题和反馈（对后续优化有价值）

## 三、数据评估与决策

### YODA原则

**Your Own DAta（你自己的数据）**

✅ **只相信真实的用户行为数据**
- ❌ 不依赖朋友说"这个想法不错"
- ❌ 不依赖问卷调查的"我愿意购买"
- ❌ 不依赖行业专家的建议
- ✅ 只看真实的支付行为

✅ **用真金白银的投入来验证**
- 最可信：用户真的付钱了
- 次可信：用户花时间填了详细表单
- 不可信：用户只是点了个赞

---

### TRI决策框架

#### 1️⃣ Think（思考）：数据告诉我什么？

**填入你的实际数据**（测试结束后）：

```
曝光量（看到内容的人数）：_______ 人
点击量（进入落地页的人数）：_______ 人
页面浏览量（PV）：_______ 次
点击购买次数：_______ 次
实际支付次数：_______ 人
转化率（支付/PV）：_______ %
预期转化率：8%
达成度：_______ %
```

**数据解读**：
- 如果达成度 ≥ 100%：✅ 超出预期，市场需求强烈
- 如果达成度 50-99%：🟡 接近预期但有差距，需要调整
- 如果达成度 < 50%：🔴 远低于预期，可能方向有问题

**示例**：
```
假设你的数据是：
- 页面浏览量：150次
- 实际支付次数：10人
- 实际转化率：6.67%
- 达成度：6.67% / 8% = 83%
```

#### 2️⃣ Refine（优化）：需要调整什么？

**决策矩阵**：

| 达成度 | 决策 | 行动 |
|--------|------|------|
| ≥ 100% | ✅ **GO** | 开发MVP，扩大测试 |
| 50-99% | 🔄 **PIVOT** | 调整后重新测试 |
| < 50% | 🛑 **STOP** | 重大调整或放弃 |

**基于示例数据（83%达成度）的决策**：🔄 **PIVOT**

**需要调整的方向**：
- [ ] **价值主张**：
  - 问题：用户可能觉得"AI个性化"不够吸引人
  - 调整：强调"3个月转行成功"的结果
  
- [ ] **定价策略**：
  - 问题：¥1999可能偏贵
  - 调整：测试¥999的价格，或提供分期付款
  
- [ ] **目标用户**：
  - 问题：25-40岁范围太广
  - 调整：聚焦28-35岁，更精准的人群
  
- [ ] **渠道选择**：
  - 问题：小红书用户付费意愿可能较低
  - 调整：增加知乎、脉脉等职场平台

#### 3️⃣ Iterate（迭代）：下一步做什么？

**如果是GO（≥100%）**：
1. ✅ **开发MVP**：
   - 先做最核心功能（AI学习路径生成）
   - 时间：4-6周
   - 成本：¥5-10万（如果外包）

2. ✅ **扩大测试**：
   - 目标：从100人扩大到1000人
   - 预算：¥5000-10000推广费用
   - 验证：更大规模下转化率是否稳定

3. ✅ **规划完整开发**：
   - 制定产品路线图
   - 组建团队或找外包
   - 准备融资材料

**如果是PIVOT（50-99%）**（基于示例数据）：
1. 🔄 **深入分析**：
   - 访谈已支付的10个用户：为什么买？
   - 访谈点击但未支付的用户：为什么不买？
   - 找出关键差距

2. 🔄 **调整方案**：
   - 假设发现价格是主要障碍：
     - 新假设：至少10%的用户会购买¥999的课程
     - 新pretotype：修改落地页价格为¥999
   
3. 🔄 **重新测试**：
   - 时间：再测1-2周
   - 预算：¥300-500
   - 目标：验证调整是否有效

4. 🔄 **设定上限**：
   - 最多pivot 2-3次
   - 如果3次后仍<80%达成度，考虑stop

**如果是STOP（<50%）**：
1. 🛑 **提取学习**：
   - 记录失败原因：
     - 市场需求不足？
     - 定价太高？
     - 价值主张不清晰？
   - 保存所有数据和反馈

2. 🛑 **评估是否值得大幅调整**：
   - 如果用户反馈"根本不需要学编程"：彻底放弃
   - 如果用户反馈"需要但价格太贵"：考虑免费+增值服务模式

3. 🛑 **考虑转向其他想法**：
   - 也许"职场技能提升"比"学编程"需求更广
   - 也许"AI简历优化"比"AI学编程"更刚需

4. 🛑 **不要沉没成本陷阱**：
   - 已经花了¥500和1周时间
   - 但如果继续投入可能浪费几十万和一年时间
   - 及时止损是正确的

### 关键提醒

⚠️ **不要犯这些错误**：

1. ❌ **样本量太小就下结论**
   - 错误：只有20个人看过就说"没人需要"
   - 正确：至少要达到最小样本量（114人）

2. ❌ **测试时间太短**
   - 错误：测试3天就放弃
   - 正确：至少1-2周，给用户决策时间

3. ❌ **只看好的数据，忽略坏数据**
   - 错误："虽然只有2个人买，但他们都说很好"
   - 正确：转化率只有1.3%，远低于8%目标

4. ❌ **用朋友家人的反馈做决策**
   - 错误："我妈说这个想法很好"
   - 正确：朋友家人的意见不算，只看陌生用户的真实行为

5. ❌ **因为已经投入就不愿放弃**
   - 错误："我已经花了¥500，不能白费"
   - 正确：¥500的沉没成本，避免了¥50万的更大损失

✅ **记住这些原则**：

1. ✅ **数据 > 意见**
   - 10个真实支付 > 100个"我觉得不错"

2. ✅ **行为 > 承诺**
   - 1个真实购买 > 10个"我肯定会买"

3. ✅ **快速失败 > 完美计划**
   - 1周测试得出结论 > 3个月做完美的商业计划书

4. ✅ **小成本验证 > 大投入开发**
   - ¥500验证需求 > ¥50万开发产品再验证

5. ✅ **做对产品 > 把产品做对**
   - 先确认方向对 > 再追求执行好
