## 三、数据评估与决策

### YODA原则

**Your Own DAta（你自己的数据）**

✅ **只相信真实的用户行为数据**
- 不依赖意见调研
- 不依赖专家建议
- 不依赖朋友反馈

✅ **用真金白银的投入来验证**
- 金钱投入最可信
- 时间投入次之
- 口头承诺不可信

---

### 切身利益卡尺

评估用户投入的真实程度：

| 投入类型 | 可信度 | 示例 | 验证强度 |
|---------|--------|------|---------|
| 💰 **金钱** | ⭐⭐⭐⭐⭐ | 付费购买、预付定金、众筹支持 | 最强 |
| ⏰ **时间** | ⭐⭐⭐⭐☆ | 注册账号、填写详细表单、观看完整视频 | 强 |
| 💪 **精力** | ⭐⭐⭐☆☆ | 学习使用、推荐他人、参与测试 | 中等 |
| 💬 **口头** | ⭐☆☆☆☆ | 说"我会买"、问卷调查、点赞评论 | 弱 |

### TRI决策框架

#### 1️⃣ Think（思考）：数据告诉我什么？

**填入你的实际数据**：

```
曝光量：_______ 人
转化数：_______ 人
实际转化率：_______ %
预期转化率：[X]%
达成度：_______ %
```

**数据解读**：
- 如果达成度 ≥ 100%：✅ 超出预期
- 如果达成度 50-99%：🟡 接近预期但有差距
- 如果达成度 < 50%：🔴 远低于预期

#### 2️⃣ Refine（优化）：需要调整什么？

**决策矩阵**：

| 达成度 | 决策 | 行动 |
|--------|------|------|
| ≥ 100% | ✅ **GO** | 进入下一阶段开发 |
| 50-99% | 🔄 **PIVOT** | 调整后重新测试 |
| < 50% | 🛑 **STOP** | 重大调整或放弃 |

**你的决策**：_______

**如果是PIVOT，需要调整**：
- [ ] 价值主张（产品卖点）
- [ ] 目标用户（换个人群）
- [ ] 定价策略（太贵/太便宜）
- [ ] 渠道选择（换个平台）
- [ ] 呈现方式（文案/设计）

#### 3️⃣ Iterate（迭代）：下一步做什么？

**如果是GO（≥100%）**：
1. 开发最小可行原型（MVP）
2. 扩大测试规模（10倍用户）
3. 开始规划完整开发
4. 考虑融资或资源投入

**如果是PIVOT（50-99%）**：
1. 深入分析：访谈已转化和未转化用户
2. 找出差距：哪里不符合预期？
3. 调整方案：针对性优化
4. 重新测试：1-2周新一轮pretotype
5. 设定上限：最多pivot 2-3次

**如果是STOP（<50%）**：
1. 提取学习：记录失败原因
2. 评估是否值得大幅调整
3. 考虑转向其他想法
4. 不要沉没成本陷阱

### 关键提醒

⚠️ **不要犯这些错误**：

1. ❌ 样本量太小就下结论（< 100人）
2. ❌ 测试时间太短（< 1周）
3. ❌ 只看好的数据，忽略坏数据
4. ❌ 用朋友家人的反馈做决策
5. ❌ 因为已经投入就不愿放弃

✅ **记住这些原则**：

1. ✅ 数据 > 意见
2. ✅ 行为 > 承诺
3. ✅ 快速失败 > 完美计划
4. ✅ 小成本验证 > 大投入开发
5. ✅ 做对产品 > 把产品做对
