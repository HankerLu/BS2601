# 分析工具（《做对产品》第6章）

用于**诠释预型试验收集到的 YODA**，判断创意有多大可能是「正确的它」，并做出继续、转型或停止的决策。引用顺序：切身利益卡尺 → TRI 计量仪 → 试验次数与决策。

---

## 1. 切身利益卡尺

### 定义
**切身利益卡尺**：给不同类型的目标市场反响分配「切身利益点」的工具。只有伴随真实投入（时间、金钱、注意力）的行为才计分；意见、点赞、调查等为 0 点。

### 原则
- 在投入大量切身利益开发创意之前，必须先让目标市场投入**他们的**切身利益；否则不能把那些人视为潜在客户，只是观众。
- 唯一有资格作为验证依据的数据是**与切身利益相关的 YODA**。

### 表6-1 要点（原著）

| 证据类别 | 示例 | 切身利益点 |
|----------|------|------------|
| 意见（专家或非专家） | “这是个好主意。” “没人会买它。” | 0 |
| 鼓励或劝阻 | “去做吧！” “还是专心做本职工作吧！” | 0 |
| 一次性或虚假的邮箱/电话 | bogus@spam.com, (123) 555-1212 | 0 |
| 社交媒体评论或点赞 | 点赞、反对、喜欢、评论 | 0 |
| 调查、投票、访谈 | “你有多大可能会购买，1～5 分？” | 0 |
| 已验证的邮箱（知情、自愿接收产品更新） | 提供邮箱以接收产品更新 | 1 |
| 已验证的电话号码（知情、用于产品通知） | 提供电话以便告知产品信息 | 10 |
| 时间承诺 | 参加 30 分钟产品演示 | 30（1 点/分钟） |
| 现金支出 | 支付 50 美元加入候补名单 | 50（1 点/美元） |
| 下单 | 支付 250 美元获取首批购买资格之一 | 250（1 点/美元） |

### 使用要点
- 卡尺可按产品与市场**定制**（如货币、时间单位），但「0 点 vs 有分数」的区分须清晰：无切身利益 = 0。
- 解读预型数据时，只把**对应到有分数的行为**当作有效 YODA；浏览、点赞、问卷得分等不能替代。

## 2. TRI 计量仪（“正确的它”计量仪）

### 定义
**TRI 计量仪**：将预型试验结果映射到 5 个「成功可能性」层级的工具，用于判断创意有多大可能是「正确的它」。只有**精心设计且亲自执行的试验**得出的、**与切身利益相关的 YODA** 才有资格用箭头在计量仪上标出；意见或他人用其他方法在其他时间完成的市场研究不应作为依据。

### 五个层级（原著）

| 成功可能性等级 | 概率区间 |
|----------------|----------|
| 非常有可能     | 71% ～ 90% |
| 有可能         | 51% ～ 70% |
| 50/50          | 31% ～ 50% |
| 不可能         | 11% ～ 30% |
| 非常不可能     | 0 ～ 10%   |

### 如何映射单次试验结果
针对每条 xyz 假说及其对应预型试验，问：**若该创意注定在市场上成功且执行彻底，这个试验有多大可能产生我们实际得到的数据？**

- 数据**大大超过**假说预测 → 箭头对准**非常有可能**
- 数据**达到或略超**假说预测 → 箭头对准**有可能**
- 数据**略低于**假说预测 → 箭头对准**不可能**
- 数据**远低于**假说预测 → 箭头对准**非常不可能**
- 数据模糊、可能损坏或难诠释 → 箭头对准 **50/50**，或丢弃该次试验

### 市场失败律
计量仪上有一支指向「非常不可能」的箭头，代表**市场失败律**：大多数新创意都会在市场上失败。需要足够多的试验和足够的 YODA，才能抵消这一默认假设，让「陪审团」（决策者）有理由支持该创意。

### 决策含义（原著逻辑）
- 多次试验的箭头多数落在**有可能**或**非常有可能** → 有较充分证据支持「正确的它」，可考虑继续推进；但仍需结合你打算投入的切身利益大小判断。
- 多数落在**不可能**或**非常不可能** → 应回到绘图板，用学到的教训调整创意或换方向。
- 书中未给出固定「分数线」或 T×0.3+R×0.5 等公式；决策依赖对整体箭头分布与自身风险的判断。

## 3. 需要多少数据 / 试验次数

### 原著要点
- **至少 3～5 次试验**；若创意涉及重大风险或重大投资（如辞职、全押公司资金），应再多做几次。
- **试验次数应与你的投资和失败后果（切身利益）的大小成正比。**
- **一次试验永远不够**，无论结果多漂亮或多糟糕。
- 样本应**代表目标市场**（约 100～1 000 具有统计意义的前提是样本能代表真正可能购买/使用的人）。

### 使用要点
- 生成行动指南时，建议用户「至少 3～5 次预型试验」，重大决策时增加次数；不写书中未出现的抽样公式或置信区间计算。

## 4. 常见陷阱

### ❌ 虚荣指标
看起来好看但不能预测成功、也不伴随切身利益的指标，例如：仅有浏览量没有转化、仅有粉丝数没有互动、仅有邮件列表规模没有打开或行动。书中强调：没有切身利益就等于没有点数。

### ❌ 过早下结论
- 仅做**一次**预型试验就做决策（书中明确：一次试验无论多漂亮都不够）。
- 样本量过小或不能代表目标市场。

### ❌ 追踪意见而非行为
**错误做法：** 问卷调查“你会使用吗？”“你愿意付多少钱？”“你喜欢吗？”——书中将这些都归为 0 点。

**正确做法：** 看人们是否真的投入切身利益，例如：提供已验证的邮箱、预购、加入等待名单、花时间参加演示等。

## 输出时如何引用本章

生成「行动指南」的**第三部分（分析工具）**时：

1. **数据资格**：说明只有**伴随切身利益的行为**才算有效 YODA；引用切身利益卡尺表 6-1 要点（0 点 vs 有分数），并说明本方案中用户将收集的行为属于哪一类。
2. **诠释方法**：说明用 **TRI 计量仪**把每次试验结果映射到五个层级（非常不可能 → 非常有可能），并简述映射规则（数据相对假说的位置 → 对应层级）。
3. **试验次数**：建议至少 3～5 次试验，重大投入时更多；提醒一次试验不足以下结论。
4. **决策**：说明根据箭头整体分布做出**继续、转型或停止**的判断，不引入书中未出现的 TRI 公式或固定分数阈值。
5. **常见陷阱**：可提醒用户避免虚荣指标、过早下结论、追踪意见而非行为（见本章「常见陷阱」）。
