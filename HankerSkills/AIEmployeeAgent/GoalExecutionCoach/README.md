# GoalExecutionCoach Workspace

这是一个专注于目标执行和任务管理的独立技能集合。

## 工作原理

当Claude Code在此路径下运行时：
- ✅ 只使用 `.cursor/skills/` 目录下的技能
- ❌ 不加载任何全局技能
- ✅ 所有技能都是本workspace专属的

## 技能列表

查看 `.cursor/skills/` 目录获取可用技能

## 使用说明

1. 确保在 `GoalExecutionCoach/` 目录下工作
2. 只能使用此workspace中定义的技能
3. 要添加新技能，请在 `.cursor/skills/` 下创建新的skill目录
