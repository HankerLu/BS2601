# Skill Template

这是新技能的模板文件。复制此目录并重命名来创建新技能。

## 如何创建新技能

1. 复制整个 `_template/` 目录
2. 重命名为你的技能名称（如 `task-planner/`）
3. 编辑 `SKILL.md` 文件，定义你的技能
4. 在 `scripts/` 下添加实现脚本（如需要）
5. 在 `tests/` 下添加测试用例（如需要）

## SKILL.md 基本格式

```markdown
# 技能名称

## 描述
一句话描述技能的功能

## 触发词
用户使用哪些词会触发此技能

## 使用场景
- 场景一
- 场景二

## 执行步骤
1. 步骤一
2. 步骤二
3. 步骤三

## 输入参数
- 参数1: 说明
- 参数2: 说明

## 输出结果
描述技能执行后的输出
```
